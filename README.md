# 🛒 Retail Sales & Profit Analytics Dashboard

## 📌 Project Overview
This project features an interactive Power BI dashboard created to analyze retail sales performance, regional profitability, customer behavior, and product category trends. It transforms raw sales data into actionable business intelligence to help stakeholders identify growth opportunities and optimize product margins.

🎯 Key Performance Indicators (KPIs)
* **Total Customers:** 200
* **Total Revenue:** $212.99M
* **Overall Profit Margin:** 32.27%
* **Category Count:** 3 Primary Categories (Electronics, Office Supplies, Computer Accessories)

🔍 Key Insights & Visual Features
* **Payment Mode Performance:** Evaluates total profit generated across Credit Card, Debit Card, UPI, Cash, and Net Banking.
* **Regional Analysis:** Tracks profit distribution across South, Central, West, North, and East regions.
* **Product Profitability Breakdown:** Displays itemized profit margins across individual products (e.g., Desk Lamps, Keyboards, Power Banks) to highlight top margin drivers.
* **Category & Subcategory Sales:** Treemap and bar chart visualizations tracking revenue for Hardware, Accessories, Stationery, and Furniture.
* **Interactive Slicers:** Sidebar filter pane allowing dynamic cross-filtering by **Gender**, **City**, **Region**, and **Payment Mode**.


## 🛠️ Tools & Technologies
* **Business Intelligence:** Power BI Desktop
* **Data Processing & Modeling:** Power Query, Data Analysis Expressions (DAX)
* **Dataset Format:** Microsoft Excel (`PowerBI_DAX_Practice_Dataset.xlsx`)
